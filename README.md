# NOX Deobfuscator

**Бесплатный десктопный деобфускатор для Lua / Luau.** Открываешь обфусцированный скрипт — получаешь читаемый код: определение обфускатора, расшифрованные строковые константы, восстановленный поток управления и структура функций.

Работает полностью на твоём компьютере. Ни ключей, ни активаций, ни учётных записей, ни своего сервера.

## О приложении

NOX Deobfuscator — настольный инструмент промышленного уровня для анализа и деобфускации Lua / Luau. Он не «ищет строки в тексте»: он определяет обфускатор, разбирает виртуальную машину и восстанавливает читаемый код.

Бесплатный — но внутри это не набор скриптов, а полноценное приложение:

- **собственное ядро разбора** — лексер, парсер, форматтер, детекторы семейств и пайплайн преобразований;
- **три изолированных движка деобфускации** — Luraph, Prometheus / WeAreDevs, MoonSec;
- **контроль ресурсов** — каждый движок живёт в отдельном процессе с приватным рабочим каталогом, вычищенным окружением и отключённой сетью; дерево процессов снимается при отмене, таймауте и закрытии приложения;
- **механизм обновлений** с проверкой целостности файла до запуска установщика;
- **изолированный IPC-мост** — рендерер не имеет доступа к Node.js.

Часть внутренних компонентов взята из открытых проектов и доработана:

| Что | Что изменено |
| --- | --- |
| Тулкит Prometheus / WeAreDevs | Вызовы `eval` заменены на безопасный whitelist-вычислитель чисел; вызовы функций и работа с атрибутами отклоняются; зависимость от `networkx` и `colorama` сделана необязательной |
| Деобфускатор Luraph | Обёрнут в отдельный процесс с приватным временным каталогом, отключённой сетью и проверкой результата разбором Lua |
| Среда Luau | Используется как полностью офлайн-песочница исполнения: реальные сервисы Roblox недоступны |
| Интерфейс | Собственный: редактор с подсветкой, Diff «рядом» и «встроенно», монтаж с исходником, журнал операций |

**Автор и поддержка:** [@NoxDeobfuscator](https://t.me/NoxDeobfuscator) в Telegram.

## Возможности

- **Открытие файлов** `.lua`, `.luac` и `.txt` через диалог, перетаскиванием в окно или из списка недавних.
- **Определение обфускатора**: Luraph, Prometheus / WeAreDevs, MoonSec — по служебным заголовкам, маркерам виртуальной машины и структурным признакам.
- **Быстрый разбор**: лексический и синтаксический анализ, метрики, структурные эвристики, безопасное декодирование числовых escape-последовательностей, форматирование по токенам. Код **не исполняется**.
- **Глубокая девиртуализация**: подъём виртуальной машины Luraph v15 / v14.x, разбор Prometheus / WeAreDevs, девиртуализация байткода MoonSec V2 / V3.
- **Режим трассировки** для Luraph: фиксация поведения скрипта, когда полный подъём виртуальной машины не удаётся.
- **Пайплайны Prometheus**: полный проход или выборочный срез — «Строки», «Константы», «Управляющий поток», «VM», «Очистка».
- **Монтаж с исходником**: Monaco-редактор с подсветкой Lua, режим «рядом» и «встроенно», навигация по изменениям, сравнение версий.
- **Экспорт** результата в `.lua` или `.txt` с приложенным отчётом и контролем совпадения имён.
- **Дампер**: загрузка лоадера по прямой ссылке или из текста скрипта-лоадера, разбор вложенных этапов, перенос результата в редактор.
- **Живой прогресс** движка, отмена задачи с завершением всего дерева процессов, журнал операций.
- **Обновления**: приложение само находит новую версию и скачивает дельтой в несколько мегабайт.

> [!NOTE]
> Интерфейс, отчёты и сообщения об ошибках — на русском языке.

## Как это работает

Внутри два независимых слоя.

**Слой 1 — статический разбор.** Собственный лексер, парсер и форматтер Lua, детекторы семейств и пайплайн преобразований. Работает в фоновом потоке и никогда не исполняет анализируемый код.

**Слой 2 — глубокие движки.** Реальные деобфускаторы, вендорённые в репозиторий:

| Движок | Что делает | Язык |
| --- | --- | --- |
| **Luraph VM** | Полный подъём виртуальной машины v15 / v14.x: константы, управляющий поток, структура функций | JS + Luau |
| **Prometheus / WeAreDevs** | Эвристический разбор текста: строки, константы, поток управления | Python |
| **MoonSec V2 / V3** | Девиртуализация байткода, восстановление прототипов | Python |

Каждый движок запускается **отдельным процессом** с изолированным окружением: временные каталоги перенаправлены внутрь приватного workspace, переменные `PYTHONHOME` / `PYTHONPATH` / `NOX_*` вычищены, сетевые запросы заблокированы. Дерево процессов снимается при отмене, таймауте и закрытии приложения.

Пайплайн разбора:

```
файл
  └─ lexer → parser (luaparse) → метрики → детекторы семейств
       └─ декод escape-последовательностей → форматтер → проверка результата разбором
            └─ (по желанию) глубокая девиртуализация → повторный статический разбор
                 └─ сравнение «до / после» → экспорт
```

Каждый шаг показывает, что именно он сделал, сколько токенов затронул и какие были предпосылки.

## Быстрый старт

1. Скачай и установи приложение.
2. Перетащи `.lua` файл в окно или нажми **«Открыть файл»** (`Ctrl+O`).
3. Нажми **«Анализ»** (`Ctrl+Enter`) — увидишь определение обфускатора, метрики и найденные признаки.
4. Нажми **«Обработать»** (`Ctrl+Shift+Enter`) — получишь расшифрованные строки и отформатированный код.
5. Для тяжёлых случаев переключи режим на **«Глубокий»** и запусти девиртуализацию.

Разбор идёт в фоне, прогресс виден, задачу можно отменить в любой момент.

## Режимы разбора

| Режим | Что делает | Исполняет код? |
| --- | --- | --- |
| **Быстрый** | Метрики, определение семейства, декод escape-последовательностей, форматирование | Нет |
| **Luraph VM · полная** | Поднимает виртуальную машину, восстанавливает функции и управляющий поток | Да — в изолированной офлайн-песочнице Luau |
| **Luraph VM · трассировка** | Записывает поведение скрипта, не поднимая машину целиком | Да — в изолированной офлайн-песочнице Luau |
| **Prometheus / MoonSec · полный** | Эвристически восстанавливает строки, константы и управляющий поток | Нет — только текст |
| **Prometheus / MoonSec · срез** | Выполняет только выбранную часть конвейера (строки, константы, поток, VM, очистка) | Нет — только текст |

> [!WARNING]
> Пайплайн Prometheus / MoonSec **эвристический**: на сложных сборках он может вернуть частичный или семантически неточный код, оставить служебные маркеры или повредить числовые литералы. Приложение помечает такой результат как экспериментальный и показывает предупреждение — проверяй вывод в редакторе и Diff перед использованием.

Автовыбор движка предпочитает явные маркеры семейства и делает одну резервную попытку другим движком, если файл похож сразу на два семейства. Режим вручную: **Настройки → Глубокие движки**.

## Дампер

Модуль «Дампер» загружает лоадер по ссылке:

- прямая ссылка на `.lua`;
- строка вида `game:HttpGet("…")`, `Url = "…"`, любой `http(s)://`-адрес в тексте.

Ответ (до 50 МБ) разбирается на вложенные этапы, ссылки на следующие шаги показываются отдельно, а сам скрипт можно сразу перенести в редактор и разобрать.

Загрузка идёт **потоком**: таймаут без активности и жёсткий лимит размера, крупный ответ обрывается на лету и не занимает память целиком.

## Обновления

Приложение проверяет наличие новой версии само — через 12 секунд после запуска, в фоне, и по кнопке **«Проверить»** в **Настройках → Обновления**.

- Метаданные релиза лежат прямо в GitHub Releases (`latest.yml` рядом с установщиком) — отдельного сервера не нужно.
- Обновление приходит **дельтой**: обычно несколько мегабайт вместо ста.
- Целостность скачанного файла проверяется по контрольной сумме `sha512` **до** запуска установщика.
- Установка не трогает настройки и историю.

## Приватность и безопасность

- `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true` — рендерер не имеет доступа к Node.js.
- Узкий preload-мост: наружу отдаются только перечисленные методы; `fs`, `child_process` и сырой `ipcRenderer` недоступны.
- Файлы читаются **только те, что выбрал пользователь**: системный диалог, перетаскивание в окно или список недавних. Произвольный путь через IPC запросить нельзя.
- Быстрый режим **не исполняет** анализируемый код.
- Глубокие движки исполняют файл только в изолированной офлайн-песочнице Luau, без доступа к сети и реальным сервисам Roblox.
- Дочерние процессы запускаются с изолированным окружением: временные каталоги внутри приватного workspace, вычищенные `PYTHONHOME` / `PYTHONPATH` / `NOX_*`, заблокированные сетевые прокси.
- Промежуточные файлы пишутся в приватный временный каталог и удаляются после запуска — даже если движок завершился ошибкой.
- Содержимое разбираемых файлов не пишется в состояние приложения и никуда не передаётся. Единственный сетевой запрос — проверка обновлений; она не блокирует запуск и молча пропускается без сети.
- CSP ограничивает источники скриптов, стилей, изображений и воркеров.

## Частые вопросы

**Нужен ли интернет?** Нет. Приложение полностью работает офлайн; сеть нужна только чтобы скачать обновление.

**Почему SmartScreen ругается?** Файл установщика не подписан цифровой подписью. Это предупреждение Windows, а не ошибка приложения.

**Что означает «экспериментальный» результат?** Что вывод движка получен эвристиками, а не точным разбором виртуальной машины. Проверь результат в Diff, прежде чем использовать его.

**Запускается ли мой код?** Быстрый режим — нет, никогда. Глубокий режим Luraph исполняет файл в изолированной песочнице Luau без сети и без доступа к реальным сервисам Roblox. Prometheus, MoonSec и дампер работают только с текстом.

**Куда уходят мои файлы?** Никуда. Они читаются с диска, разбираются локально и удаляются из временного каталога после обработки.

**Поддерживается ли `.luac`?** Файл распознаётся, но байткод не дизассемблируется — доступен только статический разбор текста.
